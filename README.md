# Villa Control — Home Assistant Floorplan

Interactive Home Assistant floorplan concept derived from the embedded preview of the supplied AutoCAD DWG.

- Premium responsive UI
- Interactive room selection
- Lights, blinds and climate mock controls
- Home / Night / Away scenes
- Desktop, tablet and mobile layouts
- Public demo intentionally uses mock data only

The original DWG is **not** published in this repository.

> Note: room labels are provisional because the DWG embedded thumbnail does not expose readable room names. The geometry/data mapping is separated so labels and real Home Assistant entity IDs can be replaced without redesigning the UI.
